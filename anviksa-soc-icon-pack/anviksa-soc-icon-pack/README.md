# ANViKSa SOC Icon Pack

This is the dashboard-specific layer for the ANViKSa Supervisory SOC interface shown in the supplied UI references.

## Design direction
- Lucide-inspired outline icons
- tuned for ANViKSa's dark navy interface
- 20px default navigation size
- cyan active state
- green healthy / verified state
- red critical state
- amber warning state
- purple intelligence / analysis state
- deliberately restrained rather than cartoonish

## Feature coverage
Command Centre, Supervisory, Findings, Analytics, Risk Quantification, Threat Recurrence, Analyst Workload, Alert Streams, Incidents, Investigations, Supervisory Cases, Evidence Vault, Hash Ledger, Session Enclave, Reports, Simulation Hub, Enclave Settings, Live Activity, Real-Time Telemetry, Crypto Ledger, threat intelligence, hunting, playbooks, response, SIEM, SOAR, network, endpoints, servers, logs, vulnerabilities, malware, access control, identity, cloud, API keys, data sources, integrations and common dashboard actions.

## Usage
SVG files are in `svg/`. React/TypeScript components are in `react/`. `theme.css` contains the ANViKSa semantic color tokens and icon-state classes. `anviksa-icon-map.json` maps product feature names to icon assets.
